# Compose

Insert files and images, and aggregate blocks and changes into the shapes Build Page (JSON) and Apply Content Changes accept.

| Component | Description |
|---|---|
| [Build Insert File](BuildInsertFile.md) | Builds an insert_files Change JSON and matching Image Blocks from a file path, Bitmap, URL, base64 string or Rhino viewport capture. |
| [Blocks Aggregator](PageBlocksAggregator.md) | Gathers Block JSON from Rich Content blocks and Build Insert File into the Blocks JSON list for Build Page (JSON). |
| [Content Changes Aggregator](ContentChangesAggregator.md) | Flattens every wired Change JSON into one ordered batch, capped at the API limit of 50. |
