# Pages

Build page Document JSON and turn it into insert_page / update_page Change JSON. Pure JSON assembly, no network calls.

| Component | Description |
|---|---|
| [Build Page (Markdown)](BuildPageMarkdown.md) | Builds a page's Document JSON from a plain Markdown body. |
| [Insert Page](InsertPage.md) | Builds one insert_page Change JSON op per Document JSON item. |
| [Update Page](UpdatePage.md) | Builds one update_page Change JSON op per Page ID. |
| [Build Pages From Tree](BuildPagesFromTree.md) | Builds one insert_page or update_page Change JSON op per branch item from parallel trees of page properties. |
| [Markdown Table From Grid](MarkdownTableFromGrid.md) | Builds a Markdown table from a Header Row and a rows x columns Grid tree. |

The JSON-block page path, [Build Page (JSON)](../Rich%20Content/BuildRichPage.md), is on the **Rich Content** tab.
