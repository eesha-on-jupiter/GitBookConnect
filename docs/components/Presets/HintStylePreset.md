# Hint Style

A value-list preset of GitBook hint (callout) styles, for Hint Block's Style input.

## Inputs

None.

## Outputs

One unnamed value-list output carrying the selected value as a quoted string.

## Values

| Display Name | Value |
|---|---|
| Info | `info` |
| Warning | `warning` |
| Danger | `danger` |
| Success | `success` |

## Feeds into

- [Hint Block](../Rich%20Content/BuildHintBlock.md)'s `Style` input.

## Notes

- A Grasshopper value list: pick an entry from its dropdown.
