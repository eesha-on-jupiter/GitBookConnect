# Presets

Value-list shortcuts for GitBook's enum-like string inputs.

| Component | Description |
|---|---|
| [Hint Style](HintStylePreset.md) | A value-list preset of GitBook hint (callout) styles, for Hint Block's Style input. |
| [Text Color](TextColorPreset.md) | A value-list preset of GitBook colour tokens, for Color Mark's Text Color and Background Color inputs. |
