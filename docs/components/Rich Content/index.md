# Rich Content

Wrap Text JSON runs into GitBook blocks: paragraphs, headings, hints, expandables, cards and tables, then assemble them into a page with Build Page (JSON). Pure JSON assembly.

| Component | Description |
|---|---|
| [Paragraph Block](ParagraphBlock.md) | Wraps one or more styled Text JSON runs into a paragraph block. |
| [Heading Block](HeadingBlock.md) | Wraps one or more styled Text JSON runs into a heading block. |
| [Hint Block](BuildHintBlock.md) | Builds a hint (callout) block from styled Text JSON runs. |
| [Expandable Block](BuildExpandableBlock.md) | Builds a collapsible (expandable) block from a title and styled Text JSON runs. |
| [Cards Block](BuildCardsBlock.md) | Builds a cards layout (a columns block) from parallel lists of card titles, texts and icons. |
| [Table Block](TableBlock.md) | Builds a GitBook table block from a Header Row and a rows x columns Grid tree. |
| [Build Page (JSON)](BuildRichPage.md) | Builds a page's Document JSON from assembled Blocks JSON. |
