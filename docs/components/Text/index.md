# Text

Build styled inline text: start with Plain Text, then chain marks, one style per component. Pure JSON assembly.

| Component | Description |
|---|---|
| [Plain Text](PlainText.md) | Wraps a raw string into a Text JSON leaf with no marks. |
| [Bold Mark](BoldMark.md) | Adds a bold mark to a Text JSON leaf. |
| [Italic Mark](ItalicMark.md) | Adds a italic mark to a Text JSON leaf. |
| [Strikethrough Mark](StrikethroughMark.md) | Adds a strikethrough mark to a Text JSON leaf. |
| [Code Mark](CodeMark.md) | Adds a code mark to a Text JSON leaf. |
| [Keyboard Mark](KeyboardMark.md) | Adds a keyboard mark to a Text JSON leaf. |
| [Superscript Mark](SuperscriptMark.md) | Adds a superscript mark to a Text JSON leaf. |
| [Subscript Mark](SubscriptMark.md) | Adds a subscript mark to a Text JSON leaf. |
| [Color Mark](ColorMark.md) | Adds a text and/or background colour mark to a Text JSON leaf. |
