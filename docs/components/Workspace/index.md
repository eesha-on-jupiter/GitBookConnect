# Workspace

Read-only navigation of organizations, spaces and collections, to find the IDs other components need. Every component is button-triggered.

| Component | Description |
|---|---|
| [List Organizations](GetAllOrganizations.md) | Lists every GitBook organization the token can access. |
| [Get Organization](GetOrganization.md) | Retrieves one GitBook organization by ID. |
| [List Spaces](GetAllSpaces.md) | Lists every space in a GitBook organization. |
| [Get Space](GetSpace.md) | Retrieves one GitBook space by ID. |
| [List Collections](GetAllCollections.md) | Lists every collection in a GitBook organization. |
| [Get Collection](GetCollection.md) | Retrieves one GitBook collection by ID. |
